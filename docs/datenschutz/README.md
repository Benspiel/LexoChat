# Datenschutz-Paket LexiChat

> **Entwurf – ersetzt keine Rechtsberatung. Vor Produktivbetrieb durch Datenschutzbeauftragte(n)/Rechtsanwalt prüfen lassen.**

Diese Vorlagen beschreiben die technische Umsetzung von LexiChat so genau wie möglich. Sie machen die Praxis **nicht automatisch DSGVO-konform**: Rechtsgrundlagen, Fristen und organisatorische Maßnahmen müssen von der verantwortlichen Stelle geprüft, angepasst und umgesetzt werden.
